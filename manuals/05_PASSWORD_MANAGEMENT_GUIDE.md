# 🔐 Password Management Guide
## How to Manage Your Password Securely

---

## Overview

This guide explains how to change your password, create strong passwords, and maintain account security. Protecting your account is essential for patient data security.

---

## 🎯 Why Password Security Matters

### Importance

**Your password protects:**
- Patient medical images
- Sensitive health information
- Your professional account
- System integrity
- Compliance with regulations (HIPAA, etc.)

**Consequences of Weak Passwords:**
- Unauthorized access to patient data
- Data breaches
- Legal liability
- Loss of license
- System compromise

## 🔑 Changing Your Password

### When to Change Password

**Change your password:**
- Every 90 days (recommended)
- If you suspect compromise
- After sharing with someone (never do this!)
- When prompted by system
- After security incident
- When leaving shared computer

### Step-by-Step Password Change

**Complete Process:**

1. **Login to Your Account**
   - Go to application URL
   - Enter email and current password
   - Click **"Login"**

2. **Navigate to Profile**
   - Click on your name/icon (top-right corner)
   - Select **"Profile"** or **"Settings"**
   - Profile page opens

3. **Find Password Section**
   - Scroll to **"Change Password"** section
   - Or click **"Security"** tab
   - Password change form appears

4. **Fill in Password Form**
   ```
   Current Password: [Enter your current password]
   New Password: [Enter your new password]
   Confirm New Password: [Re-enter new password]
   ```

5. **Password Requirements**
   ```
   Your password must:
   ✓ Be at least 8 characters long
   ✓ Contain at least one uppercase letter (A-Z)
   ✓ Contain at least one lowercase letter (a-z)
   ✓ Contain at least one number (0-9)
   ✓ Contain at least one special character (!@#$%^&*)
   
   Optional but recommended:
   ○ Be 12+ characters for extra security
   ○ Avoid common words
   ○ Avoid personal information
   ```

6. **Verify Password Strength**
   ```
   Password Strength Indicator:
   
   Weak:     ████░░░░░░ (Too short or simple)
   Fair:     ████████░░ (Meets minimum requirements)
   Strong:   ████████████ (Recommended)
   ```

7. **Submit Change**
   - Click **"Update Password"** button
   - Wait for confirmation

8. **Success Confirmation**
   ```
   ✓ Password Changed Successfully!
   
   Your password has been updated.
   Please use your new password for future logins.
   ```

9. **Logout and Test**
   - Logout from your account
   - Login with new password
   - Verify access works

## 🛡️ Creating Strong Passwords

### Password Best Practices

**DO:**
✅ Use 12+ characters  
✅ Mix uppercase and lowercase  
✅ Include numbers and symbols  
✅ Use unique password for this system  
✅ Use a password manager  
✅ Create memorable but complex passwords  

**DON'T:**
❌ Use personal information (name, birthday)  
❌ Use common words or phrases  
❌ Reuse passwords from other sites  
❌ Share your password with anyone  
❌ Write password on paper  
❌ Use sequential numbers (123456)  

### Password Creation Methods

#### Method 1: Passphrase

**Create a memorable sentence:**

```
Example Sentence:
"I love working at City Hospital since 2020!"

Password:
ILw@CH$2020!

Explanation:
- First letters of each word
- Replace 'a' with '@'
- Replace 's' with '$'
- Add year and exclamation
```

#### Method 2: Random with Pattern

**Use a pattern you can remember:**

```
Pattern: [Word][Symbol][Number][Word][Symbol]

Example:
Blue@2024$Sky!

- Two words you like
- Symbols between
- Important number
- Easy to remember, hard to guess
```

#### Method 3: Password Manager Generated

**Use password manager:**

```
Generated Password:
K9$mP2@vL5#nQ8

Advantages:
- Maximum security
- Unique for each site
- Manager remembers it
- Auto-fills on login
```

### Password Examples

**Weak Passwords (NEVER USE):**
```
❌ password123
❌ admin2024
❌ hospital
❌ 12345678
❌ qwerty
❌ yourname123
```

**Strong Passwords (GOOD):**
```
✓ Tr3@t!ng_P@t!3nts_2024
✓ M3d!c@l#Imag3$2024
✓ H0sp!t@l&C@r3*2024
✓ S@f3_D@t@_Pr0t3ct!0n
```

## 🔄 Password Reset by Admin

### When Admin Resets Your Password

**Scenarios:**
- You forgot your password
- Account locked after failed attempts
- Security incident
- Admin-initiated reset

### What Happens

1. **Admin Resets Password**
   - Admin creates temporary password
   - You receive notification (email or phone)

2. **Receive Temporary Password**
   ```
   Your temporary password: Temp@2024!Pass
   
   Important:
   - Use this to login once
   - Change immediately after login
   - Do not share this password
   ```

3. **First Login with Temporary Password**
   - Go to login page
   - Enter your email
   - Enter temporary password
   - Click **"Login"**

4. **Forced Password Change**
   - System prompts password change
   - Cannot proceed without changing
   - Follow password change steps above

5. **Set Your New Password**
   - Create strong password
   - Follow requirements
   - Save securely

## 🚨 Forgot Password

### Self-Service Password Recovery

**If Available:**

1. **Click "Forgot Password"**
   - On login page
   - Click **"Forgot Password?"** link

2. **Enter Your Email**
   - Type your registered email
   - Click **"Send Reset Link"**

3. **Check Your Email**
   - Look for password reset email
   - Check spam folder if not in inbox
   - Email contains reset link

4. **Click Reset Link**
   - Link valid for 24 hours
   - Opens password reset page

5. **Create New Password**
   - Enter new password
   - Confirm new password
   - Click **"Reset Password"**

6. **Login with New Password**
   - Return to login page
   - Use new password

### Contact Administrator

**If Self-Service Not Available:**

1. **Contact Your Admin**
   - Email or call system administrator
   - Provide your registered email
   - Verify your identity

2. **Wait for Reset**
   - Admin will reset your password
   - You'll receive temporary password

3. **Follow Admin Reset Process**
   - See "Password Reset by Admin" section above

## 🔒 Account Security Tips

### Login Security

**Secure Login Practices:**

1. **Always Logout**
   - Click logout when finished
   - Don't just close browser
   - Especially on shared computers

2. **Lock Your Screen**
   - Lock computer when away
   - Windows: Win+L
   - Mac: Cmd+Ctrl+Q

3. **Use Private Browsing**
   - For shared computers
   - Doesn't save passwords
   - Clears data on close

4. **Check URL**
   - Verify correct website
   - Look for HTTPS (secure)
   - Beware of phishing sites

### Password Storage

**Secure Storage Methods:**

**✅ Recommended:**
- Password manager software (LastPass, 1Password, Bitwarden)
- Encrypted password vault
- Secure notes app with encryption

**❌ Not Recommended:**
- Plain text file on computer
- Sticky notes on monitor
- Shared documents
- Email to yourself
- Browser-saved passwords (on shared computers)

### Multi-Factor Authentication (MFA)

**If Available:**

1. **Enable MFA**
   - Go to Security Settings
   - Enable Two-Factor Authentication
   - Follow setup instructions

2. **MFA Methods**
   - SMS code to phone
   - Authenticator app (Google Authenticator, Authy)
   - Email verification
   - Security key

3. **Login with MFA**
   - Enter password
   - Enter MFA code
   - Access granted

**Benefits:**
- Extra security layer
- Protects even if password stolen
- Required for sensitive data

## 🚫 What NOT to Do

### Never Do These

**❌ Share Your Password**
- Not with colleagues
- Not with IT support (they can reset)
- Not with family
- Not with anyone

**❌ Write Password Down**
- Not on paper
- Not on sticky notes
- Not in plain text files
- Not in unsecured locations

**❌ Use Same Password Everywhere**
- Each system needs unique password
- Breach on one site affects all
- Use password manager to track

**❌ Send Password via Email/Text**
- Email is not secure
- Text messages can be intercepted
- Use secure communication only

**❌ Use Public WiFi Without VPN**
- Public networks are insecure
- Passwords can be intercepted
- Use VPN or mobile data

## ⚠️ Security Warnings

### Recognize Security Threats

**Phishing Emails:**
```
Warning Signs:
- Urgent password reset requests
- Suspicious sender email
- Spelling/grammar errors
- Links to unfamiliar websites
- Requests for personal information

Action:
- Do not click links
- Do not provide password
- Report to IT/Admin
- Delete email
```

**Suspicious Activity:**
```
Warning Signs:
- Login from unknown location
- Failed login attempts
- Unexpected password reset emails
- Account changes you didn't make

Action:
- Change password immediately
- Contact administrator
- Review account activity
- Enable MFA if available
```

### Account Lockout

**After Failed Login Attempts:**

1. **Account Locked**
   ```
   ⚠ Account Locked
   
   Too many failed login attempts.
   Your account has been locked for security.
   
   Contact administrator to unlock.
   ```

2. **Contact Admin**
   - Email or call administrator
   - Verify your identity
   - Explain situation

3. **Account Unlocked**
   - Admin unlocks account
   - You may need to reset password
   - Login with new credentials

## 🆘 Troubleshooting

### Issue: Current Password Not Accepted

**Solutions:**
1. Verify Caps Lock is off
2. Check for extra spaces
3. Try typing slowly
4. Use "Show Password" option
5. Reset password if forgotten

### Issue: New Password Rejected

**Solutions:**
1. Check all requirements met
2. Ensure passwords match
3. Avoid common passwords
4. Try different password
5. Contact admin if persists

### Issue: Cannot Access Profile

**Solutions:**
1. Refresh the page
2. Clear browser cache
3. Try different browser
4. Logout and login again
5. Contact administrator

### Issue: Password Reset Email Not Received

**Solutions:**
1. Check spam/junk folder
2. Verify email address correct
3. Wait 10-15 minutes
4. Request new reset email
5. Contact administrator
