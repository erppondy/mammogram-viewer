# 📜 License Status Guide
## Understanding Your Ambulance License

---

## Overview

This guide explains your ambulance license, how to check its status, understand quotas, and what to do when your license is expiring or has issues.

---

## 🎯 What is an Ambulance License?

### License Basics

**Your License:**
- Authorizes your ambulance to use the system
- Controls how many images you can upload
- Has an expiration date
- Unique to your ambulance/organization
- Managed by system administrator

**License Key Format:**
```
AMB-XXXX-XXXX-XXXX-XXXX

Example: AMB-A1B2-C3D4-E5F6-G7H8
```

**What License Controls:**
- Upload access (yes/no)
- Upload quota (number of images)
- License duration (validity period)
- Number of users from your ambulance
- Storage allocation

## 🚦 License Status Indicators

### Status Types

#### 🟢 Active (Green)

**Meaning:**
- License is valid and working
- You can upload images
- All features available
- No action needed

**Display:**
```
✓ Active
Your license is valid
```

#### 🟡 Expiring Soon (Yellow)

**Meaning:**
- License expires in less than 30 days
- Still functional
- Action needed soon
- Contact admin to renew

**Display:**
```
⚠ Expiring Soon
Your license expires in 15 days
Contact administrator to renew
```

**What to Do:**
1. Note expiration date
2. Contact your administrator
3. Request license extension
4. Plan for renewal

#### 🔴 Expired (Red)

**Meaning:**
- License validity period ended
- Cannot upload new images
- Can view existing images
- Must renew to continue

**Display:**
```
✗ Expired
Your license expired on [Date]
Contact administrator immediately
```

**What to Do:**
1. Contact administrator urgently
2. Request license renewal
3. Cannot upload until renewed
4. Existing images still accessible

#### ⚫ Revoked (Black)

**Meaning:**
- License terminated by administrator
- All access suspended
- Cannot upload or view
- Contact admin for explanation

**Display:**
```
✗ Revoked
Your license has been revoked
Contact administrator for details
```

**What to Do:**
1. Contact administrator immediately
2. Understand reason for revocation
3. Resolve any issues
4. Request new license if eligible

## 📈 Understanding Upload Quota

### What is Upload Quota?

**Definition:**
- Maximum number of images you can upload
- Set by administrator
- Counts each image file
- Resets when license renewed (if applicable)

**Example:**
```
Quota: 1000 images
Used: 450 images
Remaining: 550 images
```

### Quota Display

**Visual Indicator:**
```
Upload Quota: 450 / 1000

Progress Bar:
████████████░░░░░░░░░░░░░░░░ 45%

Status: Good
```

### Quota Levels

#### Green Zone (0-79% Used)

**Status:** Healthy
```
Used: 450 / 1000 (45%)
Status: ✓ Good
```

**Action:** None needed

#### Yellow Zone (80-89% Used)

**Status:** Warning
```
Used: 850 / 1000 (85%)
Status: ⚠ Warning - Quota Running Low
```

**Action:**
- Monitor usage closely
- Plan to contact admin
- Prepare for quota increase request

#### Orange Zone (90-99% Used)

**Status:** Critical
```
Used: 950 / 1000 (95%)
Status: ⚠ Critical - Contact Admin Soon
```

**Action:**
- Contact administrator immediately
- Request quota increase
- Prioritize essential uploads only

#### Red Zone (100% Used)

**Status:** Exceeded
```
Used: 1000 / 1000 (100%)
Status: ✗ Quota Exceeded - Cannot Upload
```

**Action:**
- Cannot upload new images
- Contact administrator urgently
- Request quota increase
- Wait for admin to increase quota

### Quota Warnings

**Automatic Alerts:**

**At 80% Usage:**
```
⚠ Quota Warning

You have used 80% of your upload quota.
Remaining: 200 images

Consider contacting your administrator
to increase your quota.
```

**At 90% Usage:**
```
⚠ Critical Quota Alert

You have used 90% of your upload quota.
Remaining: 100 images

Please contact your administrator
immediately to increase your quota.
```

**At 100% Usage:**
```
✗ Quota Exceeded

You have reached your upload limit.
No uploads available.

Contact your administrator to increase
your quota before uploading more images.
```

**14 Days Before:**


**7 Days Before:**
```

```

**On Expiration Day:**
```
✗ License Expired

Your license expired today.
You can no longer upload images.

Contact administrator to renew immediately.
```

### What Happens When License Expires

**Immediately:**
- Cannot upload new images
- Upload button disabled
- Warning message displayed

**Still Available:**
- Can view existing images
- Can download your images
- Can view annotations
- Can access your account

**Not Available:**
- Cannot upload new images
- Cannot create new annotations
- Cannot use system features

## 🔄 License Renewal Process

### How to Request Renewal

**Step 1: Contact Administrator**
```
Email Template:

Subject: License Renewal Request - [Your Ambulance Name]

Dear Administrator,

I am writing to request renewal of our ambulance license.

License Details:
- Ambulance: [Your Ambulance Name]
- License Key: AMB-XXXX-****-****
- Current Expiration: [Date]
- Current Quota: [Number]

Please renew our license for another [period].
We would also like to [increase/maintain] our upload quota.

Thank you,
[Your Name]
[Contact Information]
```

**Step 2: Wait for Admin Response**
- Administrator reviews request
- May ask for additional information
- Processes renewal

**Step 3: License Extended**
- Administrator extends license
- New expiration date set
- You receive notification

**Step 4: Verify Renewal**
- Check dashboard
- Verify new expiration date
- Confirm quota if changed
- Resume normal operations

## 🆘 Common License Issues

### Issue: Cannot Upload - License Expired

**Problem:**
```
✗ Upload Failed
Your license has expired
```

**Solution:**
1. Verify expiration date on dashboard
2. Contact administrator immediately
3. Request license renewal
4. Wait for renewal confirmation
5. Try upload again after renewal

### Issue: Cannot Upload - Quota Exceeded

**Problem:**
```
✗ Upload Failed
Upload quota exceeded (1000/1000)
```

**Solution:**
1. Check quota on dashboard
2. Contact administrator
3. Request quota increase
4. Explain usage needs
5. Wait for quota increase
6. Try upload again

### Issue: License Status Shows "Revoked"

**Problem:**
```
✗ License Revoked
Contact administrator
```

**Solution:**
1. Contact administrator immediately
2. Ask for revocation reason
3. Resolve any issues
4. Request license reactivation
5. May need new license

### Issue: License Information Not Showing

**Problem:**
- Dashboard shows no license
- License section blank

**Solution:**
1. Refresh the page
2. Logout and login again
3. Clear browser cache
4. Try different browser
5. Contact administrator if persists

## 💡 Best Practices

### Proactive Management

**Stay Ahead:**
1. **Monitor Weekly**
   - Check status every week
   - Track quota usage
   - Note expiration date

2. **Plan Ahead**
   - Request renewal 30 days before expiration
   - Request quota increase at 70% usage
   - Don't wait for warnings

3. **Communicate**
   - Keep administrator informed
   - Report usage patterns
   - Discuss future needs

4. **Document**
   - Keep license key secure
   - Note expiration dates
   - Track renewal history

### Quota Management

**Optimize Usage:**

1. **Upload Efficiently**
   - Upload only necessary images
   - Avoid duplicates
   - Delete test uploads

2. **Batch Uploads**
   - Group related images
   - Upload complete studies
   - Reduce partial uploads

3. **Quality Over Quantity**
   - Ensure image quality
   - Verify before uploading
   - Avoid re-uploads

4. **Plan Capacity**
   - Estimate monthly needs
   - Request appropriate quota
   - Allow buffer for peaks
