- Digital Imaging and Communications in Medicine

- Study Date, Modality
- Institution Name
- No manual data entry!

✅ **Advanced Viewing**
- Window/Level adjustment
- Zoom and pan

- DICOM to PNG for web viewing
- Maintains image quality
- Cached for performance
